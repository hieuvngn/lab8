Lab 8 - JSF Application

Chào mừng đến với Lab 8 - JSF

Ứng dụng quản lý sinh viên sử dụng JavaServer Faces (JSF)

Các tính năng:

  • ✅ Hiển thị danh sách sinh viên
  • ✅ Thêm sinh viên mới với validation
  • ✅ Sửa thông tin sinh viên
  • ✅ Xóa sinh viên
  • ✅ Tìm kiếm sinh viên theo từ khóa
  • ✅ Hiển thị message thành công/thất bại

Công nghệ sử dụng:

  • Java EE / Jakarta EE
  • JSF 2.3 (JavaServer Faces)
  • Maven
  • PrimeFaces (UI Components)
